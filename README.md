# Number Guessing Game

A simple Python console game where the computer generates a random number between 1 and 100 and the player tries to guess it.

## Features
- Random number generation
- Unlimited attempts
- Higher/Lower hints
- Attempt counter

## Technologies Used
- Python 3

## How to Run

```bash
python guess_game.py
```

## Example

Guess a number: 50
Higher number please

Guess a number: 75
Lower number please

Guess a number: 63
You have guessed correctly in 3 attempts
